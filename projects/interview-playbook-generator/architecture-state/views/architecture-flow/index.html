    Flow: Auto-Generate Architecture Diagrams (flow:workflow:github:auto-generate-architecture-diagrams)

    • Type: workflow
    • Sequence:
    • Determine ref to checkout
    • Checkout Code
    • Prevent loops (skip if last commit made by the bot)
    • Set up Python
    • Install Dependencies
    • Generate Architecture Diagrams
    • Verify Git Status (Check for uncommitted diagram changes)
    • Commit and push generated diagrams back to branch

    Flow: CAS Continuous Architecture Loop (flow:workflow:github:cas-continuous-architecture-loop)

    • Type: workflow
    • Sequence:
    • Checkout Target Repository
    • Set up CAS CLI
    • Pre-flight Environment & Credential Check
    • Run Deterministic Architecture Linter & Control Bands
    • Checkout Central Knowledge Layer (cas-brain/knowledge)
    • Run Continuous Architecture Synthesis Loop
    • Run Pattern Discovery & Classification Flow
    • Commit & Push Updated Architectural Models to Central Brain

    Flow: CAS Skill Evaluations (flow:workflow:github:cas-skill-evaluations)

    • Type: workflow
    • Sequence:
    • Checkout repository
    • Set up CAS CLI
    • Run Deterministic Skill Evaluations

    Flow: CAS SDD & TDD Validation (flow:workflow:github:cas-sdd-tdd-validation)

    • Type: workflow
    • Sequence:
    • Checkout Code
    • Set up CAS CLI
    • Check Commit Exemption
    • Validate SDD & TDD Compliance Across Configured SDLC Profile
    • Validate Architectural Guardrails (Anti-Pattern Linter - ARCH-LINT-001, ARCH-LINT-002, ARCH-LINT-003: provider-agnostic-llm-client)
    • Verify Statistical Control Bands
    • Evaluate Agent Skills
