    Flow: CAS Build Steering Projection (flow:workflow:github:cas-build-steering-projection)

    • Type: workflow
    • Sequence:
    • Checkout
    • Prepare Workspace
    • Set up Python
    • Set up uv
    • Clean projection directory
    • Run steering projection
    • Capture projection ID
    • Upload projection bundle
    • Job summary

    Flow: CAS Build Validation (flow:workflow:github:cas-build-validation)

    • Type: workflow
    • Sequence:
    • Checkout
    • Checkout Knowledge Layer
    • Set up Python
    • Set up uv
    • Install dependencies
    • Run Governance Validator
    • Run build and contract validation
    • Write validation summary
    • Upload validation report

    Flow: CAS Continuous Architecture Loop (flow:workflow:github:cas-continuous-architecture-loop)

    • Type: workflow
    • Sequence:
    • Checkout repository
    • Checkout Knowledge Layer
    • Set up Python
    • Install uv
    • Install dependencies
    • Run Continuous Architecture Loop
    • Commit and Push changes
    • Upload Artifacts

    Flow: CAS Managed Steering Sync (flow:workflow:github:cas-managed-steering-sync)

    • Type: workflow
    • Sequence:
    • actions/checkout@v4
    • Check if commit contains only steering changes
    • Set up Python
    • Install uv
    • Install dependencies
    • Run Steering Projection
    • Upload Projection
    • actions/checkout@v4
    • Prepare Workspace
    • Download Projection
    • Set up Python
    • Install uv
    • Install dependencies
    • Create Sync Branch
    • Inspect Projection
    • Apply Managed Sections
    • Commit Changes
    • Create or Update Pull Request

    Flow: CAS Governance Portal Publish (flow:workflow:github:cas-governance-portal-publish)

    • Type: workflow
    • Sequence:
    • Checkout CAS Runner
    • Clean knowledge environment
    • Checkout Knowledge Layer
    • Set up Python
    • Install uv
    • Install Dependencies & MkDocs Plugins
    • Pre-process Portal Content
    • Build Portal
    • Add CNAME for Pages
    • Configure git for external repository
    • Deploy to GitHub Pages
